# A NoiseScope session's program for the unit at Bellevue (tasks/phase-3.16/README.md, *The garden
# instead of the bench*). **It needs a release carrying phase 3.17's task 01** - the settle a
# `scope` gets when it names none, which is 500 us - and task 03 of the pile before it for `us`
# and `dev` to be in the frames.
#
# The same 60 MHz as session C, in today's segments, with the settle moved. Three of these lines
# were run as session 9 on 25 November and they are what the default rests on: with no settle the
# first six points of each segment read -64.5, -74.5, -74.5, -78.5, -88.5 and -91.5 dBm in the
# frames holding the neighbour at -33 dBm, and -98.5 where the floor is -104.5 in the frames
# without it; with 500 us they read the floor in both, and 2 000 us is no better
# (tasks/phase-3.16/FOLLOWUPS.md, *What the garden said: sessions 6 to 9*).
#
# So the list has turned round. **The line a session types now stands 500 us by itself**, and the
# reference - the sweep that stands on nothing, which is what every line typed before phase 3.17's
# task 01 did - is the one that has to say so, with `max 32 0`. Step 1 is that reference and step 2
# is the plain line, and the two of them together are the proof of the default: the first six
# points of each segment standing up in step 1 and at the floor in step 2.
#
# **What moved to make the room** (`max 32 0` is nine characters and the program was 384 bytes of
# 384): the 100 us step is gone - it was never run, and the question it asked, *is 100 already
# enough to see the block go*, is answered by 500 being enough and 2 000 buying nothing - and the
# 500 us step is now the plain line, which is the same sweep in nine characters fewer. Five steps,
# 328 bytes of 384; a step's line is still at most forty characters and the longest here is 39.
#
# the settle on a segment's first point
--- garden-d
seconds = 85
# the reference: 60 MHz at 467 kHz, two segments, and no stand on either first point at all
today-0 = scope 840 900 0 467 1000 max 32 0
# the same line as a session types it, which stands the default 500 us on each first point
default = scope 840 900 0 467 1000
# and 2 000 us, where more can buy nothing the synthesizer has not already had
settle-2000 = scope 840 900 0 467 1000 max 32 2000
# 13 MHz at 58.6 kHz around the signal, one segment, and no stand on its one first point
narrow-0 = scope 863 876 250 58.6 1000 max 32 0
# and the same 13 MHz with 1 000 us on it
narrow-1000 = scope 863 876 250 58.6 1000 max 32 1000
